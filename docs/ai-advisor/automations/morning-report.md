## 動作の要点（レビュー用）

- 拾う条件は保存ビュー「自動化_実行待ち」（`未着手` または `実行中`＋`完了観点` あり、`対象日` ≤ 今日）。1 ページ目 10 行。
- ルール整理（同系の旧発効を失効・発効日補完）→ 準備（繰り返し展開・連鎖起票・再確認起票・不足の再評価）→ 実行（ロック → 起動条件 → 観点解決 → 本文の頭 → 観点ループ → 統合 → 判断行 → 仕上げ → 通知）。
- 本文は `作成中（k/m 観点）` で始め、観点ごとに節を追記、全観点後に `## 統合`。`判断` 行は骨格だけ（`最終判断` は人）。
- personal-only は成立／未成立のみ。エントリー帯は条件文、サイズは金額。
