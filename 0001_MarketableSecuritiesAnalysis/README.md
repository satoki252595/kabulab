# XBRL財務分析システム

このプロジェクトは、EDINET（Electronic Disclosure for Investors' NETwork）からダウンロードしたXBRL形式の有価証券報告書から財務データを抽出・分析するシステムです。

## 機能概要

1. **有価証券分析**（デフォルト）
   - 投資有価証券と受取配当金の分析
   - 資産比率・配当比率の計算
   - 営業利益率・売上高成長率の算出
   - Yahoo Finance APIによる時価総額取得

2. **連結経営指標分析**（新機能）
   - 有報1章の連結経営指標等を包括的に抽出
   - 5年分の売上高、営業利益、経常利益、当期純利益
   - 総資産、純資産、財務比率（ROA、ROE、自己資本比率）
   - 1株当たり指標（EPS、BPS）
   - 従業員数

## ファイル構成

### 主要ファイル
- `xbrl_financial_analyzer.py` - メイン分析システム
- `getXBRL.py` - EDINETからのXBRLデータダウンロード
- `setDB.py` - データベース格納機能
- `test_management_indicators.py` - 連結経営指標抽出のテスト

### その他
- `downloads/` - EDINETコードマッピングデータ
- `xbrl/` - XBRLファイル格納ディレクトリ
- `archive_old_files/` - 過去のファイル（重複機能の統合により移動）

## 使用方法

### 1. 有価証券分析（デフォルト）
```bash
python xbrl_financial_analyzer.py
```

### 2. 連結経営指標分析
```bash
python xbrl_financial_analyzer.py --management-indicators
```

### 3. ヘルプ表示
```bash
python xbrl_financial_analyzer.py --help
```

### 4. テスト実行
```bash
python test_management_indicators.py
```

## 出力形式

### 有価証券分析
- CSV形式で以下の項目を出力：
  - 銘柄コード、企業名、時価総額
  - 投資有価証券（当期・前期）
  - 受取配当金（当期・前期）
  - 資産比率、配当比率、営業利益率、売上高成長率

### 連結経営指標分析
- CSV形式で以下の項目を出力：
  - 基本情報（銘柄コード、企業名、EDINETコード）
  - 売上高（当期〜4期前）
  - 利益項目（営業利益、経常利益、当期純利益）
  - 資産項目（総資産、純資産）
  - 財務比率（ROA、ROE、自己資本比率）
  - 1株当たり指標（EPS、BPS）
  - 従業員数

## システム特徴

- **包括的な指標抽出**: 1章の連結経営指標等を網羅的に抽出
- **5年分の時系列データ**: 当期から4期前までの推移を把握
- **複数XBRLバージョン対応**: 2018-2022年の各タクソノミーに対応
- **エラーハンドリング**: ファイル破損や形式違いに対する堅牢性
- **進捗表示**: 大量ファイル処理時の進捗確認
- **柔軟な出力**: 指標別データ取得状況の詳細レポート

## 技術仕様

- **言語**: Python 3.7+
- **主要ライブラリ**: 
  - pandas（データ処理）
  - yfinance（市場データ取得）
  - xml.etree.ElementTree（XBRL解析）
  - requests（API通信）
- **入力形式**: XBRL（eXtensible Business Reporting Language）
- **出力形式**: CSV（UTF-8エンコーディング）

## 注意事項

- XBRLファイルは事前にダウンロードしておく必要があります
- Yahoo Finance APIによる時価総額取得にはインターネット接続が必要です
- 企業によって開示項目が異なるため、一部指標が取得できない場合があります
- 大量ファイル処理時は時間がかかる場合があります

## プロジェクト履歴

このプロジェクトは、当初の投資有価証券分析機能から始まり、ユーザーからの要望を受けて以下の改善を重ねました：

1. 配当比率の修正（適切なタグの追加）
2. 投資有価証券抽出精度の向上（子会社株式の除外）
3. 時価総額取得の改善（Yahoo Finance API利用）
4. 前年データ対応の追加
5. 連結経営指標の包括的抽出機能の追加
6. プロジェクト構成の整理・統合

29個の重複ファイルを統合し、1つの包括的なシステムとして再構築されました。
